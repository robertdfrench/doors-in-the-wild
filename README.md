# Doors in the Wild
*A nice and accurate survey of every door in illumos-gate*

```progress
8.04% Complete
```

The **Tradecraft** section describes common door techniques
*observed* in illumos-gate. It is not a set of recommendations;
it describes merely what is, not necessarily what *should be*.

The **Sightings** section details non-trivial use of doors in
various daemons, administrative tools, and kernel components.
Sightings are grouped by major topic area, and may occasionally
span more than one executable or library.

The **Miscellany** section details trivial use of doors, some of
which is clever or interesting or funny, and some of which is
not.
